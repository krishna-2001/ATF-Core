# ATF-Core

ATF is an experimental, open-source framework for request-level
cryptographic identity in APIs and agent-based systems.

ATF focuses on:
- Signed requests (no shared secrets or bearer tokens)
- Verifier-controlled trust
- Explicit revocation, caching, and failure behavior

This project is a research-driven reference implementation and
is not production-ready.

## Status
Early exploration / open for discussion and collaboration.
